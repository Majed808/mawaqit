# مواقيت — تذكير بمواقيت الصلاة والإقامة

تطبيق ويب تقدمي (PWA) خفيف ومستقل: **108 KB** إجمالًا (≈48 KB مضغوطًا)، بلا مكتبات تشغيل، بلا خادم، بلا حساب، ويعمل دون إنترنت.

## مصدر المواقيت (تم التحقق)
منصة منهاج (portal.themwl.org) تحسب المواقيت على خادمها عبر واجهة داخلية
`POST /api/salat/prayer-times {latitude, longitude, zoneId}` وتختار الطريقة حسب **المنطقة الزمنية**:

| المنطقة | الطريقة | الفجر | العشاء | تعديل |
|---|---|---|---|---|
| `Asia/Riyadh` | أم القرى | 18.5° | المغرب + 90 دقيقة | — |
| غيرها | رابطة العالم الإسلامي | 18° | 17° | الظهر +1 دقيقة |

العصر: ظل المثل. التقريب لأقرب دقيقة. خطوط العرض المرتفعة: قاعدة منتصف الليل.

الواجهة غير موثقة، ولا تعرض إلا «اليوم»، وتتطلب إرسال موقع المستخدم؛ لذلك تُحسب المواقيت **محليًا** بخوارزمية Meeus نفسها،
وطوبقت مع المنصة في **24 حالة** (7 مدن سعودية + 17 حالة دولية وعبر المناطق الزمنية) بتاريخ 2026-11-17 — **صفر فروقات**.
البيانات المرجعية في `tools/ref-2026-11-17.json`.

**غير متحقق منه:** سلوك المنصة في رمضان (لا تعرض أيامًا قادمة). خيار «العشاء +120 دقيقة في رمضان» متاح ومعطّل افتراضيًا.

## التشغيل والبناء
```bash
npm install        # esbuild فقط (أداة بناء، لا تُشحن مع التطبيق)
npm run dev        # http://localhost:5173
npm test           # 48 اختبار: الدقة + الجدولة + منع التكرار + المناطق الزمنية + التوقيت الصيفي
npm run build      # يشغّل الاختبارات ثم يبني dist/
npm run preview    # يعرض dist/ على http://localhost:5174
```

## النشر والمشاركة
**الرابط المباشر:** https://majed808.github.io/mawaqit/

لنشر أي تحديث: `npm run deploy` (يختبر ويبني ثم يدفع `dist/` إلى فرع `gh-pages`). تُحفظ إعدادات المستخدمين عند التحديث.

انسخ محتويات `dist/` إلى أي استضافة ثابتة تعمل بـ HTTPS (مطلوب للـ Service Worker والإشعارات):
GitHub Pages أو Netlify أو Cloudflare Pages. الرابط الناتج هو رابط التثبيت والمشاركة.

## الإشعارات — القيود الفعلية لكل منصة
| المنصة | الوضع |
|---|---|
| Windows / macOS (Chrome/Edge مثبّت) | تعمل والنافذة مفتوحة أو مصغّرة. لما بعد إعادة التشغيل: فعّل «Start app when you sign in». |
| Android (Chrome مثبّت) | تعمل والتطبيق مفتوح أو في الخلفية؛ إذا أغلقه النظام كليًا لا تصل. |
| iOS 16.4+ | يلزم «إضافة إلى الشاشة الرئيسية»؛ موثوقة والتطبيق مفتوح فقط. |

لا توجد في متصفحات اليوم واجهة لجدولة إشعار محلي يعمل والتطبيق مغلق تمامًا (Notification Triggers أُلغيت).
الحل الوحيد لذلك هو Web Push عبر خادم صغير يرسل التنبيه في وقته — غير مضاف لأن المتطلبات تمنع الخادم إلا عند الضرورة، ويحتاج قرارًا منك.

## التنبيهات والتطبيق مغلق (خادم Web Push)
`push-server/` — Cloudflare Worker + قاعدة D1 + مهمة كل دقيقة (الخطة المجانية).
- يرسل التطبيق تنبيهات 30 يومًا (الأوقات والنصوص فقط، دون الموقع أو اسم المدينة)، ويجددها عند فتحه.
- الخادم يرسل كل تنبيه في وقته عبر خدمة إشعارات الجهاز (Apple / Google / Microsoft / Mozilla)، مشفّرًا (RFC 8291) وموقّعًا (VAPID).
- لا يُرسل أي تنبيه مرتين، وتُحذف الأجهزة المنتهية تلقائيًا، ويُنبَّه الجهاز إذا قاربت الجدولة على الانتهاء.

```bash
cd push-server
npm test                 # اختبار التشفير مقابل المرجع
node test/e2e.mjs        # اختبار شامل محلي (wrangler dev + D1 + خدمة دفع وهمية)
npx wrangler login       # مرة واحدة (في PowerShell استخدم npx.cmd)
node deploy.mjs          # ينشئ D1 ومفاتيح VAPID وينشر ويكتب src/config.js
```
مفتاح VAPID الخاص محفوظ في أسرار Cloudflare وفي `push-server/.vapid.json` (خارج git) — احتفظ به لإعادة النشر.
